# Own and edit financial data without the plugin

Status: Accepted
Date: 2026-09-12

Money Manager keeps the complete financial record inspectable, directly editable,
and usable without the plugin. The user owns portable documents under the same
sync and backup practices as the rest of the vault, so retaining the record does
not depend on keeping the plugin installed.

## Consequences

Direct edits are part of the supported workflow and can require diagnostics.
The storage alternatives and preservation requirements that implement this
commitment are recorded in
[ADR-0001](../../adr/0001-keep-markdown-canonical.md).
